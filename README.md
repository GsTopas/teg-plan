# TEG Leveranceplan

Statisk single-page app der viser en delt 18-måneders leveranceplan.
Data ligger i Supabase (login påkrævet); denne side er kun app-skallen.

Hostet via GitHub Pages fra dette repo.

Databaseopsaetningen (tabeller, adgangsregler, funktioner og triggere) er
gemt i [`supabase/schema.sql`](supabase/schema.sql) som backup. Opdater den
naar skemaet aendres i Supabase.
